# Zonke Contribution

## What problem did it solve?
Zonke is the company's freelance marketplace. It needed profile image and PDF document uploads, a live deployment, and a redevelopment direction using Laravel.

## What did I build? (my role)
- Tested changes allowing users to update profiles with images and PDF documents
- Deployed Zonke to the web with cPanel, fixing file-path and version problems
- Troubleshot the document upload and proposed how to combine team projects
- Worked in the team responsible for user document inputs, testing and bug-finding in the Laravel redevelopment

## Tech used
PHP, Laravel, cPanel, Git/GitHub

## Result
Site deployed to the web after resolving path and version problems; document-upload feature tested.
