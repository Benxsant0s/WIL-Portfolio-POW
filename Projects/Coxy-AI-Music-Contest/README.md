# Coxy AI Music Contest

## What problem did it solve?
The Coxy wallet needed a more engaging feature. The AI Music Contest lets users connect a Cardano wallet, pay an entry fee, submit AI-generated music and vote on entries. This was a design and documentation project.

## What did I build? (my role)
- Documented purpose and objectives (wallet connection, entry-fee payment, music submission, voting)
- Mapped the full user journey
- Documented features and technologies (Haskell, PHP, Cardano, Mesh SDK)
- Documented accessibility and responsive-design requirements
- Wrote test cases and improvement recommendations

## Tech used
Haskell, PHP, Cardano, Mesh SDK (design level), Markdown

## Result
Complete design documentation set and test suite covering 9 areas (navigation, wallet connection, 10 ADA payment, form fields, MP3/WAV upload, 25 MB limit, playback, voting, screen sizes).

## How to run or view it
Read the documents in `Documentation/`. No running build was produced for this project.
