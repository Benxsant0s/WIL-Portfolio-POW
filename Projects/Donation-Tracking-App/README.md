# Donation Tracking App

## What problem did it solve?
Donations needed to be recorded and tracked with their Cardano transaction IDs, with an AI assistant to answer questions about them.

## What did I build? (my role)
- Presented and demonstrated the CoxyAI Donations App to the facilitator and CTO
- Fixed four security issues: cross-site scripting via donor names, public database file, unsafe cross-origin setting, missing input validation
- Added validation for amounts, purposes and Cardano transaction IDs
- Corrected wrong AI-assistant answers
- Added summary statistics, breakdown by purpose, search/filtering, CSV export, transaction-ID storage and a light/dark interface
