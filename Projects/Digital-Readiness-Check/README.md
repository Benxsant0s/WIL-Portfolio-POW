## What problem did it solve?

## What did I build? (my role)
- Researched the Tobb Technologies website and cited credible sources
- Wrote the marketing project proposal
- Built a working prototype of the Digital Readiness Check
- Proposed a quarterly benchmark report and a monthly free clinic run by supervised interns
